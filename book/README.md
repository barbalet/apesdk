# ApeSDK Book

Start with [the synopsis](synopsis.md), then read the chapters in order.

The practical chapters cover [building and testing](chapter_12.md),
[the Python library](chapter_13.md),
[Bronze occupations and economies](chapter_14.md), and
[the Canterbury city-host profile](chapter_15.md).

Chapters 1–12 describe the original native engine. Profile notes in the affected
chapters explain where `BRONZE_SIM` extends that behavior and `CANTERBURY_SIM`
hands policy to a city host. Chapters 14–15 describe the additions in this
checkout; population limits and host responsibilities must be read against the
consumer's pinned SDK revision.

This directory is a narrative guide to the current ApeSDK source tree. It is
intended for people who want to understand how the artificial life engine is put
together before they begin changing code, writing experiments, or preparing a
release.
