# ApeSDK Book

Start with [the synopsis](synopsis.md), then read the chapters in order.

The final practical chapters are [Chapter 12: Building, Extending, And
Stress-Testing A Living System](chapter_12.md) and [Chapter 13: Building And
Running The Python Library](chapter_13.md).

This directory is a narrative guide to the current ApeSDK source tree. It is
intended for people who want to understand how the artificial life engine is put
together before they begin changing code, writing experiments, or preparing a
release.
